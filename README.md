# Кредитный дозор: проверка признака риска на отчётности ГИР БО

Проверяем, видна ли проблема в открытой годовой отчётности эмитента раньше неуплаты по облигациям, и сравниваем с действиями рейтинговых агентств.

## Результат

| | С дефолтом, 13 компаний | Без дефолта, 29 компаний |
|---|---|---|
| Признак в отчёте до неуплаты | 6 из 13, минимум за 2,5 мес. | 5 из 29 |
| Агентства понизили рейтинг | 3 из 13 до неуплаты | 4 из 29 за год после отчёта |

Расчёт по строкам отчётности с формулами в [raschet.xlsx](raschet.xlsx).

## Признак

Считается по годовой отчётности РСБУ из ГИР БО (bo.nalog.gov.ru). Признак есть, если выполнены оба условия.

1. Стр. 4100 < 0. Денег от текущих операций не хватает на проценты, уплаченные проценты (стр. 4123) входят в 4100.
2. Стр. 2330 > 0 и стр. 2300 + стр. 2330 < 1,5 × стр. 2330. Прибыль до процентов и налога меньше 1,5 процентов к уплате.

## Выборка

- **С дефолтом.** Нефинансовые эмитенты с первым дефолтом в 2025 г. и отчётностью в ГИР БО. Берётся последний годовой отчёт до неуплаты. В счёт он идёт, только если опубликован раньше первой найденной просрочки, даже закрытой потом.
- **Без дефолта.** Эмитенты ВДО с рейтингом не выше BB+ в 2025 г., отчёт за 2024 г.
- **Агентства.** Релизы АКРА, Эксперт РА, НКР, НРА. Отзыв рейтинга не считается понижением.

## Как воспроизвести

```
python scripts/download_girbo.py
python scripts/calc_sign.py
```

Первый скрипт скачивает отчётность из ГИР БО в `data/girbo_raw.json` (уже лежит в репозитории). ГИР БО может не отвечать на зарубежные IP. Второй считает признак и итоги.

## Ограничения

- Порог 1,5 выбран на этой же выборке, нужна проверка на новых компаниях.
- История действий агентств собрана по публичным релизам, полнота не гарантирована.
- Только РСБУ. Заключения аудиторов и условия кредитов не проверялись.
- Дата публикации берётся по актуальной редакции отчёта в ГИР БО.
